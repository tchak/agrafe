# Embedded fonts

`DejaVuSansMono.ttf` is from the DejaVu fonts release 2.37
(<https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37>),
SHA-256 `b4a6c3e4faab8773f4ff761d56451646409f29abedd68f05d38c2df667d3c582`.
It is embedded in the binary to render text file thumbnails, so no font has
to be installed where the workers run. Its licence is in `LICENSE` here.
